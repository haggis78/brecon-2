The folder xslt/drafts-and-discards was created July 2026 as I went through the xslt files from the 2019 project. I am placing here two categories of xslt file: those that were unfinished attempts from 2019, and those that were completed but which created html outputs that are being culled from the rebooted project.

They are being removed from the main xslt folder to clean it up, as it's difficult to tell what each stylesheet does just from the file name. These are being saved here, rather than being deleted, because they may contain passages of code that it would be worth revisiting while building new stylesheets for the rebooted project.
